# Velix Go - Aplicativo do Passageiro 🚗 🛵

Aplicativo móvel independente para passageiros solicitarem corridas urbanas por **Carro** ou **Mototáxi**, acompanharem o motorista em tempo real pelo mapa, gerenciarem favoritos e pagarem com facilidade.

## 📱 Tecnologias
- **Flutter & Dart** (Material Design 3)
- **Supabase Backend** (Auth, PostgreSQL, Realtime, RLS)
- **Google Maps SDK**
- **Arquitetura**: Clean Architecture & Provider State Management

## 📦 Identificadores do Build
- **Pubspec Name**: `velix_go_passenger`
- **Android Package / Application ID**: `com.velixgo.passenger`
- **App Name**: `Velix Go`

## 🚀 Como Executar e Compilar

### 1. Obter dependências:
```bash
flutter pub get
```

### 2. Executar em modo Debug:
```bash
flutter run
```

### 3. Gerar APK de Produção independente:
```bash
flutter build apk --release
```

### 4. Executar Testes:
```bash
flutter test
```
